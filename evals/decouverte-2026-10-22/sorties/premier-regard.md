# Premier regard — README seul

Point d’entrée consulté : `README.md`, sans ouvrir ses liens.

Orka est un dossier de skill qui fournit des instructions de coordination de spécialistes. L’assistant hôte apporte les modèles, outils et éventuels sous-agents. L’installation ne crée pas de service permanent. Les perspectives peuvent être traitées successivement si la délégation n’est pas disponible ou autorisée.

Le parcours que je choisirais est l’installation manuelle dans Codex : télécharger le ZIP de release explicitement lié, l’extraire et copier le dossier complet `orka` dans `~/.agents/skills/orka/`, puis ouvrir une nouvelle session si nécessaire et invoquer `$orka`. Pour ce test, la destination serait un dossier de démonstration, sans toucher à l’installation personnelle. Je consulterais ensuite le guide d’installation pour contrôler le contenu du ZIP et le guide de démarrage en français afin de préparer mon premier message.

Le README suffit à identifier la commande d’invocation, le dossier attendu et un exemple de mission. Pour une première mission, je fournirais le projet, le résultat demandé, les fichiers et les contraintes ; l’exemple d’étude d’un produit de réservation pour coachs est directement adaptable en français.

Je n’identifie pas de manque bloquant dans ce texte pour préparer ce parcours. Il reste à vérifier la disponibilité effective du ZIP, sa structure, l’existence des guides annoncés et leur cohérence avec les étapes. Je ne peux pas encore vérifier le chargement du skill par Codex, les droits du compte/hôte, la disponibilité des sous-agents, ni le résultat d’une mission. Les affirmations d’évaluation ne prouvent pas à elles seules une qualité supérieure, ce que le README précise déjà.

Je retiens aussi que Python n’est pas requis pour l’installation manuelle ou l’usage courant, et que les outils locaux facultatifs ne lancent pas d’agents ni ne mesurent automatiquement les coûts. Le README est en anglais mais offre un lien français ; la langue est ici une préférence de lecture, pas un blocage observé.
